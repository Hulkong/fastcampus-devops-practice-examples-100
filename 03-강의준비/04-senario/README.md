## 내용

컨테이너를 운영 중인 인스턴스에서 볼륨 용량 초과 이슈를 발생시키는 코드를 작성하기 위해, Docker를 사용하여 많은 양의 데이터를 생성하고 이를 디스크에 저장하도록 설정할 수 있습니다. 아래 예제는 Docker 컨테이너 내에서 대량의 데이터를 생성하여 인스턴스의 디스크 용량을 빠르게 채우는 스크립트를 보여줍니다.

설명
Dockerfile: ubuntu:latest 이미지를 기반으로 필요한 도구를 설치하고, 대량의 데이터를 생성하는 스크립트를 컨테이너에 복사합니다.
데이터 생성 스크립트: /data 디렉토리에 1GB 크기의 파일을 무한정 생성하는 스크립트입니다.
Docker Compose 파일: Docker 컨테이너를 정의하고 실행하는 파일입니다.
Terraform 코드: EC2 인스턴스를 생성하고, Docker 및 Docker Compose를 설치하며, 위에서 작성한 Docker 컨테이너를 실행하는 스크립트를 포함합니다.
이 코드는 실행 시 EC2 인스턴스에서 Docker 컨테이너가 실행되고, 해당 컨테이너는 대량의 데이터를 생성하여 인스턴스의 디스크 용량을 빠르게 채웁니다. 이로 인해 디스크 용량 초과 이슈가 발생할 수 있습니다.

주의 사항
이 코드는 테스트 및 교육 목적으로 사용해야 하며, 실제 운영 환경에서는 신중하게 사용해야 합니다. 예기치 않은 비용이 발생할 수 있으며, 리소스 제한을 초과하여 AWS 계정에 영향을 줄 수 있습니다. 학습 목적이라면 로컬 환경 또는 무료 계정에서 테스트를 진행하세요.
